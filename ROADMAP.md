# J-- Roadmap

This is a proposal; only v0.1 items described as implemented exist in this prototype.

## v0.1 — First interpreter prototype
- [x] Python-based line interpreter
- [x] `print("text");`
- [x] Full-line `//` comments and blank lines
- [x] Line-numbered syntax errors
- [x] Hello World example
- [x] Automated unit tests
- [ ] Verify in a real Android Python IDE
- [ ] Verify on a laptop/PC

## Future proposals
- v0.2: variables and basic data types
- v0.3: conditions and loops
- v0.4: functions
- v0.5: structured data and object-oriented features
- v0.6: modules and standard library
- v0.7: improved diagnostics and tooling
- v0.8: explore 2D graphics
- v0.9: editor/IDE prototype
- v1.0: evaluate a stable first release

Graphics, IDE, native Android support, and a compiler are future ideas—not current features.
